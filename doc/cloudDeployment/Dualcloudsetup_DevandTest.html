2. Setting Up Environment 1: Development Mode (Your Workflow)

In this environment, no python files reside on the client server. Your business logic, FastAPI scripts, and intellectual property remain on your 6GB laptop.

  1. Spin up model instances on the cloud GPU: Run Ollama/vLLM on an isolated internal port (e.g., 11434 or 8001).
  3. Open an SSH Tunnel from your local machine:

  5. Bash

ssh -L 11434:localhost:11434 user@client-cloud-ip

  3. Run your pipeline locally: Execute python -m uvicorn app.main:app or Streamlit locally on your machine. Your code communicates with localhost:11434, which transparently routes compute heavy workloads to the client’s 96GB GPU.

3. Setting Up Environment 2: Testing Mode (Client Access)

To let their team test the system (Web UI, WhatsApp webhooks, Twilio calls) while protecting your code prior to final payment, deploy a compiled Docker container.

Step 1: Compile Python Code to C-Binaries

Convert your core application (app/main.py, app/rag.py, app/voice_handler.py, etc.) into .so (shared object) binaries using Nuitka or Cython. This removes the original .py source files completely.

Bash

# Example: Compile python scripts into compiled C-extension modules

nuitka --module --remove-output app/rag.py

nuitka --module --remove-output app/voice_handler.py

Step 2: Build the Production Docker Container

Package the compiled C-binaries, along with required system dependencies (ffmpeg, CUDA runtime), into a clean Dockerfile.

Dockerfile

FROM python:3.11-slim

# Install system dependencies

RUN apt-get update && apt-get install -y ffmpeg build-essential libssl-dev git curl

# Copy only requirements and compiled .so modules (NO source .py files)

COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY app_compiled/ /app/

WORKDIR /app

# Expose separate port for Testing instance

EXPOSE 8000 8501 8502

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

Step 3: Run Isolation via GPU Container Allocation

Run the container using the NVIDIA Container Toolkit. Limit its resource utilization so it never interferes with your Dev work.

Bash

docker run -d \

  --name client-testing-app \

  --gpus '"device=0"' \

  --memory="30g" \

  -p 8000:8000 -p 8501:8501 -p 8502:8502 \

  --env-file .env.production \

  your-compiled-image:latest
